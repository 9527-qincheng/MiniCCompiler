## 一、任务目标

中间代码是"前端到后端"的转轴：把 AST 翻译成一串与目标机器无关的三地址四元式，
产物 `.quad.txt` 是四类必交产物之一。

1. **表达式 → `Operand` 递归求值**。
   - `Num` → `Operand::Const(m_iConstIdx)`（常量表位序）
   - `Ident` → `Operand::Var(m_iSymIdx)`（语义阶段回填的符号表扁平下标）
   - `BinOp` → 递归左右子树 + `GetTmpVar` + `EmitIR(Q_ADD/Q_SUB/Q_MUL/Q_DIV/
     Q_EQ/Q_NE/Q_LT/Q_LE/Q_GT/Q_GE)`
   - `UnOp` → 取负用 `Q_SUB(0, x, t)`、逻辑非用 `Q_EQ(x, 0, t)`
   - `Index` → 基址 + 下标 × 元素宽度
   - `Call` → **先把所有实参求值成操作数，再逐个发 `Q_PARA`，最后 `Q_CALL`**
2. **语句 → 四元式**。
   - `Assign` → `Q_ASSIGN`
   - `If` → `Q_JZ` 跳假出口 + `Q_JMP` 跳过 else + 两个 `Q_LABEL` 回填
   - `While` → 入口 `Q_LABEL` + `Q_JZ` 出口 + 循环体 + `Q_JMP` 回入口 + 出口 `Q_LABEL`
   - `Print` → `Q_PRINT`；`Return` → `Q_RETURN`
   - `FuncDef` → `FlushToProc(proc)`，把 `m_Codes` 挂到 `ProcEntry::m_Codes`
3. **类型转换插入**（设计文档 §8.1 类型系统表）：
   `+ - * /` 两侧一 int 一 float 时插 `ITOF`，结果 float；
   赋值 float → int 插 `FTOI` 并告警（Q9）；int / int 为整除。
4. **`&&` / `||` 必须真短路**，展开成条件跳转，不能两侧都求值再做与/或。
5. **源码位置**。四元式要能定位到源码行列，供目标代码阶段出注释、供缺陷回溯。
