## 一、任务目标

目标代码生成是挑战版的加分项，也是整条流水线的最后一环：把中间代码的四元式
翻译成能被 `gcc` 直接汇编链接的 x86-64 汇编，产物 `.asm` 跑起来要能真正输出结果。

1. **按 `QuadOp` 逐条翻译**。24 个操作码全部要有对应的指令序列，不能有"漏网"的操作码
   落到默认分支里静默跳过。
2. **双通道寄存器**。整型走 `%eax`/`%ecx`/`%edx`，浮点走 `%xmm0`/`%xmm1`；
   两类值之间的转换用 `cvtsi2ss` / `cvttss2si` 就地补转换。
3. **栈帧与栈传参**。挑战版采用**自定义栈传参**（不走 System V 寄存器传参）：
   调用方把第 i 个实参落在 `i*8(%rsp)`，被调方从 `16+8*(pos-1)(%rbp)` 取形参。
   栈帧要 16 字节对齐，否则 `printf` 会崩。
4. **数据段**。全局变量、浮点常量、字符串标签分别落 `.data` / `.bss`，
   宽度按 `Operand::m_type`（int 用 4 字节、float 用 8 字节）。
5. **程序入口**（已由组长拍板）：**MinGW main** —— `global main` + `main:`，
   用 `gcc` 链接，能在本机真正汇编链接运行、答辩现场可演示。
   不用 Linux 风格的 `_start` 占位。
6. **`printf` 输出**。`Q_PRINT` 要按操作数类型选格式串，浮点同时放 `%xmm` 与
   第 2 个整型槽以适配 Windows ABI（否则浮点打印出垃圾）。
