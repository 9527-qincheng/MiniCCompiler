# 过程文档存档（docs/archive/）

这里存放项目推进过程中的**协作与整改过程文档**。它们不是验收必交产物，
但保留了「问题是怎么被发现、怎么分工、怎么复验」的证据链，
与 `docs/验收报告.md`、`docs/项目总结.md` 里的结论互为支撑。

> 说明：所有文件均为 2026-10-12 ～ 2026-10-27 期间产生的原始文档，
> **内容未做任何改写**，仅从仓库外层目录整体搬入并分类归档。
> 若与其他文档的计数口径有出入，以 `docs/验收报告.md` 与
> `docs/项目总结.md` 的当次实测值为准。

## 一、目录结构

```
docs/archive/
├── README.md                  # 本文件（索引）
├── guides/                    # 面向组员的使用与协作说明
├── reviews/                   # 提交审查报告与分支检查记录
└── taskbriefs/                # 整改说明 / 任务书
    └── modules/               # 各模块任务书（docx，按编号）
```
