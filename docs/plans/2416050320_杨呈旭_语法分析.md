## 一、任务目标

把词法产出的 Token 序列解析成 AST，挑战版有两条硬要求：

1. **用 LL(1) 预测分析表驱动，不用递归下降**。设计文档 §4.3 给出 105 条产生式，
   §4.5–§4.9 依次推导 FIRST / FOLLOW / SELECT / LL(1) 判定 / 预测分析表，
   解析器必须是"查表 + 分析栈"的驱动器，而不是一堆手写的 `ParseXxx` 函数。
   这样才能保证"实现的文法"和"文档里的文法"是同一份东西。
2. **AST 要能承载语义动作**。18 类正式节点（`Program` / `Block` / `Decl` / `ArrayDecl` /
   `FuncDef` / `Param` / `Assign` / `Index` / `Call` / `If` / `While` / `Print` / `Return` /
   `Num` / `Ident` / `UnOp` / `BinOp` / `Empty`），每类的子节点个数与语义表一致；
   `NumNode::m_iConstIdx` 必须从 `Token` 透传，`m_iSymIdx` 留给语义阶段回填。
