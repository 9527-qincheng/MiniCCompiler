# MiniC 语法支持清单（语言子集参考）

> **适用版本**：`dev` 分支（2026-10-27，`++`/`--` 与常量折叠之后）
> **依据**：`src/parser/grammar.cpp` 的 105 条 LL(1) 产生式 + `src/lexer/token.h` 的终结符表
> **说明**：文中每一条「支持 / 不支持」都在 `build/minic.exe` 上实测过，原始记录见附录 B。
> 本文只讲**这门语言长什么样**；模块分工与待办见《各组待办清单》。

## 1. 一页速查

| 分类 | 支持什么 |
|---|---|
| 数据类型 | `int` `float` `bool` `char` `void` |
| 字面量 | 十进制整数 `123`、实数 `1.5`、字符 `'a'`（含转义）、`true` / `false` |
| 算术运算 | `+` `-` `*` `/`（无 `%`） |
| 关系运算 | `==` `!=` `<` `<=` `>` `>=` |
| 逻辑运算 | `&&` `\|\|` `!` |
| 赋值 | `=`（只能出现在语句里，**不是表达式**） |
| 语句 | 赋值 `a = 1;`、下标赋值 `a[i] = 1;`、调用 `f(x);`、`if/else`、`while`、`print(...)`、`return`、`{ }`、空语句 `;` |
| 声明 | 变量、一条声明多个变量 `int a, b;`、一维数组 `int a[10];`、函数定义 |
| 注释 | `// 单行` 与 `/* 多行 */` |

| 分类 | **不**支持（实测报错） |
|---|---|
| 运算符 | `+=` `-=` `*=` `/=` `%` `?:` `&` `\|` `^` `~` `<<` `>>` |
| 语句 | `for`、`do-while`、`break`、`continue`、`switch`、`goto` |
| 声明 | 二维 / 多维数组、数组形参、函数原型 `int f(int);`、`const`、`static`、结构体 |
| 其它 | 字符串字面量（词法能识别，语法不接受）、逗号表达式、链式赋值 `a = b = 1;`、指针、多文件 |

## 2. 词法层

### 2.1 关键字（12 个）

`int`　`float`　`bool`　`char`　`void`　`if`　`else`　`while`　`print`　`return`　`true`　`false`

> `print` 是关键字，不是库函数；`void` 可用作返回类型与形参类型。

### 2.2 标识符

以**字母或下划线**开头，后接字母、数字、下划线；区分大小写；不能与关键字同名。

```
合法：a  x1  _tmp  sum_2  Main
非法：1a（数字开头）  int（关键字）
```

### 2.3 字面量（常量）

| 类型 | 写法 | 例子 | 说明 |
|---|---|---|---|
| 整型 | 十进制数字序列 | `0` `123` `007` | **只支持十进制**；`0x1F`、`1e5` 会报错 |
| 实型 | 数字 + `.` + 数字 | `1.5` `0.25` `1.` | 必须有小数点；`.5`（缺整数部分）报 `unexpected character '.'`；`1e5` 不支持；`1.2.3` 报 `malformed number` |
| 字符 | 单引号包一个字符 | `'a'` `'0'` | 支持转义：`\n` `\t` `\0` `\\` `\'`；未知转义报 `unknown escape sequence` |
| 布尔 | 关键字 | `true` `false` | 不是 `TRUE`/`1` |
| 字符串 | 双引号 | `"hi"` | 词法层能切出 `STRING` 记号，但**语法层不接受**，`print("hi")` 报错 |

### 2.4 运算符（18 个）

```
+   -   *   /        （算术）
==  !=  <  <=  >  >=  （关系）
&&  ||  !            （逻辑）
++  --               （自增自减，前缀与后缀）
=                    （赋值，仅语句）
```

> **没有** `%`（取模）、复合赋值、位运算、三目运算符。`++` / `--` **已支持**（见 §3.4）。

### 2.5 界符（8 个）

`(`　`)`　`{`　`}`　`[`　`]`　`;`　`,`

### 2.6 注释、空白与编码

```c
// 单行注释，到行尾结束
/* 多行注释
   可以跨行 */
```

- 空白（空格 / 制表符 / 换行）只作分隔，不产生记号。
- 源文件可用 UTF-8（自动跳过 BOM）或 ASCII；**不支持中文变量名**。
- 所有错误信息带 `行:列`，例如 `error: 6:15: unexpected ')' (RPAREN)`。
- **一次编译会报出全部错误，不遇错即停**：词法、语法、语义三个阶段都是「先收集、
  最后统一汇总输出」，末尾再给出 `minic: N error(s) found, compilation failed`。
- 语法阶段有错时，语义阶段**仍然执行**——这样一批语法错不会把语义能发现的问题
  掩盖掉。此时语义产生的诊断会带后缀
  `(possibly caused by earlier lexical/syntax errors)`，提示它可能是残缺 AST
  引起的次生错误（例如漏一个分号，后面已声明过的名字可能被报成未定义）。
  判别方法：有该后缀的诊断，先修掉不带后缀的那些，再回头看它还报不报。
- 目标代码（`.asm`）仍受门禁保护：只要有任何错误就不生成，避免拿残缺 AST 落下
  一份与源码无关的半成品汇编。

## 3. 语法层

### 3.1 程序骨架

```
程序 → 声明部分 语句部分
```

- 程序 = **声明部分 + 语句部分**，两部分都可以为空（空文件也能编译通过）。
- 顶层语句是合法的：`int a; a = 1;`、`print(1);` 都能过。
- 但**声明必须排在所有语句之前**：`int a; a = 1; int b;` 会在 `int b` 处报 `unexpected 'int' (INT); expected one of: if while print return { ; 标识符`。
- 函数体内的 `{ }` 里没有这个限制，声明和语句**可以任意混排**。
- **不检查入口函数**：没有 `main` 也能编译通过。

### 3.2 声明

**变量**（可一条声明多个）：

```c
int a;
int a, b, c;
float x;  bool flag;  char ch;
```

**数组**（仅一维，长度必须是**整型常量**）：

```c
int b[10];           // ✓
int b[3+5];          // ✗ 长度只能是整型常量：expected ']', but found '+'
int n; int b[n];     // ✗ 报 expected '整型常量', but found 'n'
int m[2][3];         // ✗ 报 unexpected '['（不支持多维）
```

**函数定义**（无原型声明）：

```c
int add(int x, int y) {
    return x + y;
}

void say() {
    print(1);
}
```

- 形参写法：`类型 标识符`，多个用逗号分隔；`()` 表示无参。
- **不支持函数原型**：`int f(int x);` 报 `unexpected ';' ... expected one of: {`。
- **不支持数组形参**：写成 `int sum(int a[10], int n)` 虽能过语法，但语义阶段报 `'a' is not an array`。
- 形参个数不做检查：`int f(int x)` 用 `f()` 调用不报错。

### 3.3 语句（8 类）

| 语句 | 写法 | 备注 |
|---|---|---|
| 赋值 | `a = 表达式;` | 左值只能是裸标识符 |
| 下标赋值 | `a[表达式] = 表达式;` | 左值只能一个下标：`b[i][j] = 1;` 报错 |
| 函数调用 | `f(实参, ...);` | 必须带分号 |
| 条件 | `if (表达式) 语句` / `if (表达式) 语句 else 语句` | `else` 就近配对 |
| 循环 | `while (表达式) 语句` | 条件是任意表达式（`int` 也接受） |
| 输出 | `print(表达式);` | 必须带括号与分号；**不自动换行**，要换行写 `print('\n');` |
| 返回 | `return 表达式;` 或 `return;` | `void` 带值、非 `void` 裸 `return;` 都报错；`int` 返回 float 按 Q9 告警并截断 |
| 复合 / 空 | `{ 块项序列 }`　`;` | 支持嵌套与空语句 |

> 语句块里可以再写声明：`int main(){ int a; a=1; int b; ... }` 合法。

### 3.4 表达式与优先级

从低到高共 9 层（`||` 最低）：

| 优先级 | 运算符 | 结合性 | 产生式编号 |
|---|---|---|---|
| 1（最低） | `\|\|` | 左 | 50–52 |
| 2 | `&&` | 左 | 53–55 |
| 3 | `==` `!=` | 左 | 59–60、103–105 |
| 4 | `<` `<=` `>` `>=` | 左 | 56–58、61–64 |
| 5 | `+` `-` | 左 | 65–69 |
| 6 | `*` `/` | 左 | 70–74 |
| 7 | `!` `-`（一元）、`++` `--`（前缀） | 右 | 75–77、93–94 |
| 8 | `[ 表达式 ]`、`( 实参列表 )`、`++` `--`（后缀） | 左 | 78–81、95–96 |
| 9（最高） | 标识符、常量、`true`/`false`、`( 表达式 )` | — | 82–88 |

**注意两点与 C 不同**：

1. **关系运算符已按 C++ 分层**（`<`/`<=`/`>`/`>=` 高于 `==`/`!=`），与 C 一致。实测 `r = a == b < c;` 的 AST 是 `BinOp(EQ) [ a, BinOp(LT)[b,c] ]`，即 `a == (b < c)`；`a < b == c` 解析成 `(a < b) == c`。`<` 与 `<=` 之间仍同级左结合，`a < b <= c` 是 `(a < b) <= c`。
2. **赋值不是表达式**：`a = b = 1;`、`if (a = 1)` 都会报错，括号也救不回来。

后缀可以连用（`f(x)[i]`、`a[i]`），但下标赋值左侧只能有一个 `[ ]`。

## 4. 类型规则（实测）

| 场景 | 结果 |
|---|---|
| `int` 与 `float` 混算，结果赋给 `int` | **告警**：`implicit conversion from float to int (truncated, Q9)`，退出码仍为 0 |
| `char` 参与算术 `c + 1` | **合法**：按整型提升（C 语义），结果类型 `int` |
| `char` 参与关系 `c == 'x'` | **合法**：按整型比较，结果类型 `int` |
| `bool` 参与算术 `b + 1` | **报错**：`arithmetic operands must be numeric` |
| `bool` 参与比较 `a == b`、`a < b == b < c` | **合法**：按整型比较，结果类型 `bool`（使链式比较可用） |
| `bool` 做逻辑运算 `a && true`（`a` 是 int） | **报错**：`logical operators require bool operands` |
| `bool = int` | **告警**：`suspicious assignment between BOOL and INT` |
| `int = void 函数返回值` | **告警**：`suspicious assignment between INT and VOID` |
| 未声明就使用 | **报错**：`undefined identifier z` |
| 同作用域重复声明 / 同名形参 | **报错**：`duplicate variable 'a'` |
| 内层作用域重名（遮蔽外层） | **合法**，不报错 |

### 4.1 常量折叠（编译期求值）

生成的中间代码里，**两侧都是字面常量的算术/关系表达式会在编译期直接算出结果**，
`--dump-quads` 里看不到对应的运算四元式。这只影响产物形态，**不影响运行结果**。

| 写法 | `--dump-quads` 里看到 | 说明 |
|---|---|---|
| `a = 1 + 2 * 3;` | `(=, 7, -, a)` | 嵌套全部折掉，不产生临时量 |
| `a = 7 / 2;` | `(=, 3, -, a)` | 整除向零截断，不是 3.5 |
| `a = 2 < 3;` | `(=, 1, -, a)` | 关系运算折成布尔常量 |
| `a = 1.5 * 2.0;` | `(FTOI, 3, -, _T1)` + `(=, _T1, -, a)` | 浮点先折成 3，再按 §8.1 插转换 |
| `a = 1 / 0;` | `(/, 1, 0, _T1)` **保留** | 除数为 0 **不折叠**，让运行时暴露问题 |
| `a = 2147483647 + 1;` | `(+, 2147483647, 1, _T1)` **保留** | 整型溢出**不折叠**，行为交给运行时按 `addl` 回绕 |
| `a && b` | `JZ`/`JNZ` + 标号 **保留** | 短路有副作用语义，**不折叠** |

### 4.2 静态检查补充（哪些检查、哪些不检查）

| 场景 | 结果 |
|---|---|
| 数组下标用实数 `b[1.5]` | **报错**：`array subscript must be an integer` |
| 下标越界 `b[99]`（数组长 10） | **不检查**，静默通过 |
| 实参个数与形参不符 | **报错**：`function 'f' expects 2 argument(s), but 3 given` |
| `void` 函数带值返回 | **报错**：`void function 'g' cannot return a value` |
| 非 `void` 函数裸 `return;` | **报错**：`non-void function 'f' must return a value` |
| `int` 函数返回 float | **告警**（Q9 截断），退出码仍为 0 |
| 顶层（函数体外）的裸 `return;` | **不检查** |

## 5. 与 C 的差异一览

| # | 项目 | C | MiniC |
|---|---|---|---|
| 1 | `++` / `--` | 有 | **有**（前后缀均可，语义与 C 一致；`++5` 报 `requires a modifiable lvalue`，`++true` 报 `requires a numeric operand`） |
| 2 | 复合赋值 `+=` | 有 | 无 |
| 3 | `%` 取模 | 有 | 无 |
| 4 | 三目 `?:` | 有 | 无（`?` `:` 直接报 `unexpected character`） |
| 5 | 关系运算符分层 | `==`/`!=` 低于 `<` 等 | **与 C 一致**（已分层）；唯 `<` 与 `<=` 之间仍同级左结合 |
| 6 | 赋值作表达式 | 是 | 否，`a = b = 1;` 报错 |
| 7 | `for` / `do-while` / `break` / `continue` / `switch` | 有 | 无 |
| 8 | 多维数组 | 有 | 仅一维，长度必须是整型常量 |
| 9 | 数组作形参 | 有 | 语法可写、语义报 `'a' is not an array` |
| 10 | 函数原型 | 有 | 无，声明必须带函数体 |
| 11 | 字符串 | 有 | 仅词法识别，语法不接受 |
| 12 | `char` 运算 | 按整数参与 | **按整数参与**（同 C） |
| 13 | 声明 / 语句顺序 | 任意 | 顶层**声明必须先于语句**（函数体内不限） |
| 14 | 入口检查 | 需 `main` | 不检查 |
| 15 | 下标越界 | 未定义行为 | 不检查，不报错 |
| 16 | 常量折叠 | 编译器做 | **做**（两侧皆为常量时编译期求值；除零、整型溢出、`&&`/`\|\|` 不折，见 §4.1） |
| 17 | `print` 换行 | `printf` 由格式串决定 | **不自动换行**，要换行写 `print('\n');` |
| 18 | 实参个数检查 | 编译期报错 | **编译期报错**（同 C） |
| 19 | `return` 类型检查 | 编译期报错/告警 | **void 带值、非 void 裸 return 报错**；`int`↔`float` 只告警 |

## 6. 报错速查

| 报错原文（节选） | 你的写法 | 正确改法 |
|---|---|---|
| `'++' requires a modifiable lvalue` | `++5`、`++f(1)` | 自增自减只能作用于变量或数组元素 |
| `'++' requires a numeric operand` | `++flag`（bool 变量） | `++`/`--` 只接受 int / float / char；bool 不行 |
| `unexpected '+' (PLUS); expected one of: ( [ = ++ -- (in 标识符后续)` | `a += 1;` | `a = a + 1;` |
| `unexpected character '%'` | `a % 2` | 用循环或 `a - (a / 2) * 2` 自己算 |
| `unexpected character '?'` / `':'` | `c ? x : y` | 改写 `if / else` |
| `unexpected ';' (SEMI); expected one of: {` | `int f(int x);` | 补上函数体 `{ ... }` |
| `expected '整型常量', but found 'n' (IDENT)` | `int b[n];` | 长度改常量，或改用固定大小数组 |
| `unexpected '[' (LBRACKET); expected one of: ,` | `int m[2][3];` | 改一维，或自己用 `下标 = i*列数 + j` 换算 |
| `unexpected '[' (LBRACKET); expected one of: =` | `b[i][j] = 1;` | 一次只写一个下标 |
| `arithmetic operands must be numeric` | `b + 1`（b 是 bool） | 用 int 变量代替 bool 参与算术 |
| `relational operands must be numeric or bool` | `a = g() < 1`（`g` 是 void 函数） | 数值与 bool 才可比较；char 已按整型参与，bool 可用于链式比较 |
| `logical operators require bool operands` | `a && true`（a 是 int） | 改成 `a != 0 && true` |
| `undefined identifier z` | 未声明就用 | 先声明 `int z;` |
| `duplicate variable 'a'` | 同作用域重名 | 改名或放进 `{ }` 内层 |
| `array subscript must be an integer` | `b[1.5]` | 下标用整型 |
| `unexpected '"hi"' (STRING)` | `print("hi")` | 用 `print('h');` |
| `unexpected 'int' (INT); expected one of: if while print return { ; 标识符` | 语句后面又写声明：`int a; a = 1; int b;` | 所有声明提到语句前面，或移进函数体内 |

## 7. 示例

### 7.1 最小可运行程序

```c
int main() {
    print(1 + 2 * 3);
    return 0;
}
```

### 7.2 循环 + 数组（从 1 递增填充）

```c
int i;
int a[10];

int main() {
    i = 0;
    while (i < 10) {
        a[i] = i * i;
        i = i + 1;
    }
    i = 0;
    while (i < 10) {
        print(a[i]);
        i = i + 1;
    }
    return 0;
}
```

### 7.3 函数定义 + 递归

```c
int fact(int n) {
    if (n <= 1) {
        return 1;
    }
    return n * fact(n - 1);
}

int main() {
    print(fact(5));
    return 0;
}
```

### 7.4 同样的意思，别这么写（对照）

```c
// ✓ ++/-- 已支持（前后缀均可，语义与 C 一致）
while (a--) { b[a] = a; }

// 展开写法等价（先减再取值，与 C 里 a-- 的时序一致）
while (a > 0) { a = a - 1; b[a] = a; }

// ✗ 仍不支持的复合赋值
a += 1;      // error: 5:7: unexpected '+' (PLUS); expected one of: ( [ = ++ -- (in 标识符后续)
```
