### Step 3 —— `m_children` 子节点约定（改造 `Visit` 时必须照这个写）

| 节点 | `m_children` 约定 | 关键字段 |
|---|---|---|
| `PROGRAM` / `BLOCK` | 顶层声明… + 顶层语句…（序列，直接遍历） | — |
| `DECL` | 无子节点 | `m_type`、`m_szName`、`m_iSymIdx` |
| `ARRAYDECL` | `[DECL, 维度NUM]`（维度可空） | `m_type`、`m_szName`、`m_iArraySize`、`m_iSymIdx` |
| `ASSIGN` | `[目标(IDENT/INDEX), 表达式]` | — |
| `IF` | `[条件, then]` 或 `[条件, then, else]` | else 是 `children[2]` |
| `WHILE` | `[条件, 循环体]` | — |
| `PRINT` / `RETURN` | `[表达式]`（空 return 无子节点） | — |
| `BINOP` | `[左, 右]` | `m_op` |
| `UNOP` | `[操作数]` | `m_op` |
| `INDEX` | `[基址, 下标]` | — |
| `CALL` | `[被调标识符, 实参…]` | — |
| `NUM` | 无子节点 | `m_fValue`、`m_bIsFloat`、`m_isChar`、`m_isBool`、`m_iConstIdx` |
| `IDENT` | 无子节点 | `m_szName`、`m_iSymIdx` |
| `EMPTY` | 无子节点 | — |

> 写的时候用 `node->m_children.size()` 判长度，**不要假设一定有两个子节点**——
> `IF` 的 else 可能是空的，`RETURN` 可能是空的。

### Step 4 —— 类型推导统一走一个出口

你原代码里到处用 `TOKEN_INT_CONST` / `TOKEN_FLOAT_CONST` 判断字面量类型，
但词法产出的 token 类型是 `TOKEN_INT` / `TOKEN_FLOAT` / `TOKEN_CHAR` / `TOKEN_BOOL`，
`*_CONST` 这套名字不存在。加一个私有小工具，全程只产出这 4 个值：

```cpp
// 把 NumNode 的字面量种类映射成「类型」，全程只用这 4 个值：
// TOKEN_INT / TOKEN_FLOAT / TOKEN_CHAR / TOKEN_BOOL
TokenType SemanticAnalyzer::NumType(const NumNode* n) const
{
    if (n->m_bIsFloat) return TokenType::TOKEN_FLOAT;
    if (n->m_isChar)   return TokenType::TOKEN_CHAR;
    if (n->m_isBool)   return TokenType::TOKEN_BOOL;
    return TokenType::TOKEN_INT;
}
```

之后 `IsNumeric` / `Promote` / `DeduceBinOp` 全部基于 `NumType()` 写，
`VarEntry::m_type` 与表达式类型就能直接比对了。类型系统表见设计文档 §8.1（14 条规则）。

### Step 5 —— 查重交给符号表，不要重复报错

原代码 `VisitDecl` 里自己 `SearchVar` 报一次 "redefinition"，
然后调 `RecVar` 又报一次 "duplicate variable"——**同一个错误打印两条**。

更严重的是：`SearchVar` 是**按作用域链**查的（自内向外），
用它查重会导致内层变量无法遮蔽外层同名变量，**违反 C 语义**。

正确做法：

```cpp
void SemanticAnalyzer::VisitDecl(DeclNode* d)
{
    // RecVar 内部已做「当前作用域」查重并 EmitError，直接用它
    VarEntry* e = m_symtab.RecVar(d->m_szName, d->m_type, d->m_loc.m_iRow, d->m_loc.m_iCol);
    if (e) d->m_iSymIdx = static_cast<int>(e - m_symtab.m_VarInfoTbl.data());
}
```

- `ARRAYDECL` 走 `RecArray(name, type, size, line, col)`（符号表刚加的新接口）。
- `INDEX` 节点还要检查下标是整型（任务书 4.2 检查项）。

### Step 6 —— 常量回填（Q12）+ 字符/布尔常量自登记

`docs/interface.md` 第 9 条已登记：`'x'` / `true` / `false` 的 `Token::m_iConstIdx` 为 **-1**，
**词法没有登记，语义阶段 semantic003 要自己登记**。

```cpp
void SemanticAnalyzer::VisitNum(NumNode* n)
{
    TokenType t = NumType(n);
    if (n->m_iConstIdx >= 0)
        m_symtab.BackfillConst(n->m_iConstIdx, std::string(), t);   // 词法已登记 → 回填
    else
        m_symtab.RecConstTbl(/* 原文 */, t);                        // 字符/布尔 → 自行登记
}
```
