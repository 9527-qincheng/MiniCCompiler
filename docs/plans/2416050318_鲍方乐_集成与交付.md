## 一、任务目标

1. **仓库与流程**：建立并维护 `main` / `dev` / `feature/*` 三分支模型，配置分支保护（`main`、`dev` 均 protected，
   `required_approving_review_count = 1`，禁强推禁删除），保证任何时刻 `main` 都可构建、可演示。
2. **接口冻结点**：把第 6 章契约定稿写入 `docs/interface.md`，模块间接口变更必须先登记再改代码，
   避免各组自行改签名导致联调断裂。
3. **模块联调**：六段流水线（词法 → 语法 → 符号表 → 语义 → 中间代码 → 目标代码）全部接入 `src/main.cpp`，
   六份产物独立可控（5 个 `--dump-*` + 默认 `.asm`）。
4. **测试体系**：`build.bat test` 一键跑完全部回归，每个阶段都有自己的黄金基线，
   而不是只有端到端跑通就算过。
5. **交付物**：`docs/plans/` 收齐 12 份个人计划、验收报告、答辩材料；README 与实际代码状态一致，无悬空引用。
