## 一、任务目标

与陆禹辰、于霄共同承担语义模块。本人负责**遍历骨架与类型推导**这一侧：

1. **`Visit` 分派骨架**。`Analyze(root)` 是入口，`Visit(node)` 按 `m_eKind` 分派到
   14 个专用方法；表达式节点返回推导出的 `TokenType`，语句/声明节点返回 `TOKEN_NONE`。
   这套返回值约定是整块代码的地基——写错了，后面所有类型检查都会失效。
2. **类型推导按设计文档 §8.1**。`DeduceBinOp` 统一出口：算术运算走 `Promote`
   （int + float → float）、关系运算一律产出 `bool`、一元运算保持操作数类型、
   数组下标必须整型、`&&`/`||` 两侧必须 `bool`。
3. **先声明后使用**。`VisitIdent` 走 `SearchVar`，查不到就报 `undefined identifier` 并带行列号。
4. **常量登记（Q12）**。数字/字符/布尔常量统一在语义阶段登记，
   并在 `NumNode` 上回填 `m_iConstIdx`——字符与布尔常量原先没回填，是本模块要补的一处。
